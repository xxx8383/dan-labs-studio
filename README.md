# Dan Labs Studio

Öffentliche Seiten für die Apps von Dan Labs Studio (GitHub Pages).

- `index.html` + `start.css` – Startseite mit dem 1×1-Trainer (Deutsch/Englisch, Umschalter oben rechts),
  Screenshots und dem Kasten „Tester gesucht“. Wird nur hier gepflegt.
- `bilder/` – App-Symbol und Screenshots (WebP, verkleinert aus `docs/store/screenshots/` im App-Repo)
- `einmaleins/` – Datenschutzerklärung des 1×1-Trainers (Deutsch/Englisch).
  Quelle: `docs/website/` im App-Repo; Änderungen dort machen und hierher kopieren.
  **Adresse nicht ändern**, sie ist in der Play Console hinterlegt.

Nach dem Start im Play Store: Kasten `#tester` in `index.html` durch einen Link zum Store-Eintrag ersetzen.
