# Dan Labs Studio

Öffentliche Seiten für die Apps von Dan Labs Studio (GitHub Pages):
https://xxx8383.github.io/dan-labs-studio/

- `index.html` – Startseite **Deutsch** (1×1-Trainer, Tester gesucht, Screenshots, Fragen von Eltern)
- `en/index.html` – dieselbe Seite auf **Englisch**. Beide sind per `hreflang` verknüpft:
  **Änderungen immer in beiden Dateien machen.**
- `start.css` – Gestaltung der Startseite (ergänzt `stil.css`)
- `bilder/` – App-Symbol und Screenshots (WebP, verkleinert aus `docs/store/screenshots/` im App-Repo)
- `sitemap.xml` – für die Google Search Console
- `einmaleins/` – Datenschutzerklärung des 1×1-Trainers (Deutsch/Englisch).
  Quelle: `docs/website/` im App-Repo; Änderungen dort machen und hierher kopieren.
  **Adresse nicht ändern**, sie ist in der Play Console hinterlegt.

Nach dem Start im Play Store: Kasten `#tester` durch einen Link zum Store-Eintrag ersetzen
und die Antwort „Was kostet die App?“ anpassen.
